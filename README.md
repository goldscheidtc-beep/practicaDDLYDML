# Inventario BodegaTech

Este repositorio tiene el archivo `ddl_dml_bodega.sql`.  
El script crea la tabla **inventario** y carga 10 productos.  

## Qué hace
- Crea la tabla con columnas básicas (id, nombre, precio, stock, fecha, activo).  
- Inserta los productos iniciales.  
- Actualiza el stock de algunos productos.  
- Marca la webcam como desactivada.  
- Muestra la tabla completa con `SELECT *`
